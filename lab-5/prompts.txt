Never include IsDeleted, DeletedAt
Never include PasswordHash or ConfirmPassword for User
Never include navigation collections that cause circular JSON
Include nested DTO for direct parent (e.g. DriverDTO has ConstructorDTO with Id and Name only)
Create separate CreateDTO and UpdateDTO for POST and PUT requests

Use a private ToDTO() method in each controller for mapping. Do not return EF entities directly.
